# BMW Power BI Analysis Dashboard

## Project Overview

This project is a Power BI dashboard created to analyze BMW-related business data and present the results through interactive and easy-to-understand visualizations.

The dashboard focuses on BMW model analysis, electric vehicle analysis, customer analysis, and an executive-level overview of the available data.

## Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning
* Data Transformation
* Data Visualization
* Business Analysis
